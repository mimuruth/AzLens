What is it

One workspace, many capabilities

AzLens gives a language model a curated set of tools — files, Azure, GitHub, cost, knowledge, and SQL — through the open Model Context Protocol, and a polished chat experience to drive them.

  • Decoupled by design — each server owns one domain and ships independently.
  • Dual transport — stdio for local clients, HTTP for the cloud, one codebase.
  • Azure-native — managed identity, Key Vault, Cosmos, and Easy Auth.

Chat UI05
The front end

A chat UI that means business

  • Multi-provider models — Azure OpenAI, OpenAI, Anthropic, local — auto-discovered.
  • Auto router — cheap model for simple prompts, powerful for complex.
  • Usage & cost footer — per-turn tokens and price, overridable.
  • Tool approval — mutating tools pause for a confirmation.
  • Projects — group chats, shared instructions, drag-reorder, file grounding.
  • Artifacts — syntax highlight, SVG/JSON/HTML preview, zip download.
  • ⌘K palette — jump between chats or run any action.
  • Health panel — live online/offline dots per MCP server.
